\# 📊 EDA Project – Cardiovascular Disease Analysis



\## 📌 Project Overview



This project focuses on Exploratory Data Analysis (EDA) of a cardiovascular disease dataset containing 70,000 patient records.



The main objective is to explore health-related information, identify patterns, understand relationships between different variables, and discover insights related to cardiovascular disease.



The project covers data exploration, data cleaning, statistical analysis, and data visualization using Python.



\## 📂 Dataset Information



\- \*\*Dataset Name:\*\* Cardiovascular Disease Dataset

\- \*\*Original Source:\*\* Kaggle

\- \*\*Dataset Link:\*\* https://www.kaggle.com/datasets/sulianova/cardiovascular-disease-dataset

\- \*\*Dataset File:\*\* `cardio\_train.csv`

\- \*\*Total Records:\*\* 70,000

\- \*\*Total Columns:\*\* 13

\- \*\*Target Variable:\*\* `cardio`



\## 📋 Dataset Features



| Column | Description |

|---|---|

| id | Unique patient identifier |

| age | Patient age (recorded in days in the original dataset) |

| gender | Gender category |

| height | Height in cm |

| weight | Weight in kg |

| ap\_hi | Systolic blood pressure |

| ap\_lo | Diastolic blood pressure |

| cholesterol | Cholesterol level |

| gluc | Glucose level |

| smoke | Smoking status |

| alco | Alcohol consumption status |

| active | Physical activity status |

| cardio | Cardiovascular disease indicator (0 = No, 1 = Yes) |



\## 🛠️ Technologies Used



\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- Seaborn

\- Plotly

\- Jupyter Notebook



\## 🔍 Project Workflow



1\. Data loading and inspection

2\. Data cleaning and preprocessing

3\. Handling missing values

4\. Statistical analysis

5\. Univariate analysis

6\. Bivariate analysis

7\. Data visualization

8\. Finding patterns and insights



\## 🎯 Project Objective



To understand the relationship between health-related factors and cardiovascular disease through exploratory data analysis and visualization.
